# Supabase Functions

Tempat untuk fungsi backend yang diperlukan. Validasi otorisasi dan input di sisi server. Secret dikonfigurasi di lingkungan deployment, bukan di source.

`auth-register` / `auth-login` (branch `gipar`) adalah auth lama berbasis email sintetis; auth utama memakai phone + OTP bawaan Supabase dari app mobile.
