# Machine learning

Ruang untuk eksperimen dan komponen ML. Belum ada pipeline atau model.

- `notebooks/` — eksplorasi dengan tujuan, sumber data, metode, dan batas interpretasi.
- `src/` — kode ML yang dapat digunakan ulang setelah desain ditetapkan.
- `tests/` — pengujian kode dan kesesuaian kontrak.
- `data/` — lokasi data lokal; isi tidak dilacak Git.
- `models/` — lokasi bobot lokal; isi tidak dilacak Git.

Data dan model tidak disalin ke kerangka ini. Output ML perlu review manusia dan tidak menggantikan input manual.
