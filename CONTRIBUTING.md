# Berkontribusi

Kerangka ini belum memiliki aplikasi atau perintah build. Deskripsikan domain yang berubah, alasan, kontrak yang terdampak, dan langkah verifikasi yang benar-benar dijalankan. Jangan menyatakan pemeriksaan lulus bila belum dijalankan.

- Letakkan perubahan pada domain pemiliknya; perubahan lintas domain meninjau `contracts/`.
- Jangan commit rahasia, data pengguna, dataset, bobot model, checkpoint, atau keluaran build.
- Untuk eksperimen ML, dokumentasikan sumber dan batas data serta review manusia.
- Untuk perubahan backend, sertakan migrasi dan pengujian yang sesuai saat implementasi tersedia.
- Jangan menambahkan workflow yang mengklaim aplikasi dapat dijalankan sebelum aplikasi dibuat.

## Pull request

Sertakan tujuan, dampak pada domain/kontrak, dan validasi. Jika cara validasi belum tersedia, nyatakan bahwa verifikasi belum tersedia.
